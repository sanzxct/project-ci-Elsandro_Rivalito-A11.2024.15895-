## Deskripsi Proyek
Repositori ini dibuat untuk memenuhi tugas Capstone selama pembelajaran mata kuliah Pemrograman Web Lanjut. Proyek ini dibangun menggunakan framework **CodeIgniter 4** dengan arsitektur **MVC** (Model-View-Controller).

## Tech Stack & Environment
Proyek ini dijalankan menggunakan lingkungan **Docker** untuk memastikan konsistensi sistem.
* **Framework:** CodeIgniter v4.7.2
* **Language:** PHP 8.3
* **Web Server:** Apache (Dockerized)
* **Database:** MySQL 8.0
* **Containerization:** Docker & Docker Compose
